## 范围与判断

用户目标是 SSH 终端工具，而非重新实现 shell 语言。先交付连接工作台，终端会话借用系统 OpenSSH，避免从第一版承担终端模拟器与认证协议栈的维护成本。

Rust workspace：`windshell-core` 管理主机配置、输入约束、OpenSSH 命令构造；`windshell` 负责 Ratatui/Crossterm 界面与终端生命周期。核心不依赖 TUI，以后桌面端可复用配置与命令计划；桌面内嵌终端届时需接入 PTY/终端渲染，不预先建立空 trait 或 GUI 框架。

选择系统 ssh/scp（运行依赖 OpenSSH 9+，scp 使用 SFTP 默认协议）。复用 SSH config、Agent、ProxyJump、known_hosts、密码/键盘交互认证。连接配置不保存密码或私钥内容，不关闭主机密钥校验，不通过本地 shell 拼接命令。`--ssh-config` 将指定文件通过 `-F` 同时传给 ssh/scp，可用于独立环境；用户 SSH 配置仍须可信。

技术依据：[Ratatui 安装与后端](https://ratatui.rs/installation/)、[scp 官方手册](https://man.openbsd.org/scp.1)。单会话同步运行并继承终端；无需先引入 Tokio。空闲时阻塞等待输入，文件数据不经过 Rust 应用内存。

## 行为与不变量

- 无配置 → 启动 → 空列表，可新建连接。非法已有配置明确失败，不能按空配置覆盖。
- 新建/编辑有效主机 → 保存 → 重启可见；配置验证或写入失败 → 内存列表与原文件保持不变。
- 主机地址支持 SSH 别名、DNS、IPv4、无括号 IPv6；用户名、端口留空则交给 OpenSSH 默认值；认证选择见认证模块。
- 选中主机 Enter → 恢复终端并启动真实 SSH → exit 后回到 TUI。远端 vim/tmux 与终端尺寸由系统 SSH 处理。
- u/g → 输入本地和远端路径 → F5 或聚焦传输按钮确认 → 前台传输并显示认证/进度 → 显示退出结果并回到 TUI。Esc 在提交前取消。
- 仅单文件传输；路径按原文使用，不展开 `~`/环境变量；远端 `~` 前缀、通配符、反斜杠不支持。现有目标遵循 scp 覆盖语义，表单明确提示。取消/失败可能留下部分目标文件，不报告成功，不提供伪原子传输承诺。
- 删除只移除连接配置，需 y 确认，不触碰远端内容。
- 连接配置不记录密码或密钥内容（本轮运行时凭据及临时私钥生命周期见认证模块）；Unix 配置文件权限 0600，同目录临时文件替换，写前验证。
- 正常退出、错误与 panic 尽可能恢复终端（进程被 SIGKILL 无法保证）。
- 目标 Linux/macOS/Windows；兼容具备 UTF-8、ANSI 和原始输入能力的常见终端。48×18 以下显示尺寸提示。不承诺所有历史终端。

## 当前非目标

多标签并发会话、后台传输队列、双栏远端文件浏览、断点续传、自研 SSH 协议栈、内嵌终端模拟器、桌面 UI。高性能和高可用是设计目标；未经基准测试或故障演练不宣称量化达成。
